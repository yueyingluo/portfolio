# Yueying Luo Portfolio

Static bilingual portfolio site. Open `index.html` locally, or publish it with GitHub Pages.

## Publish with GitHub Pages

1. Push these files to a repository such as `portfolio`.
2. In the repository, open **Settings → Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**, then select `main` and `/ (root)`.
4. The site will be available at `https://yueyingluo.github.io/portfolio/`.
