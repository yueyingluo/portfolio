01

从题目理解到可执行教学动作

真正的壁垒，是整条链路在真实复杂题目上持续可靠。

A · 多模态感知
拍照 / 手写作业统一处理题干、手写步骤、公式、几何图与物理示意图。
版面分析与内容分区难点① 图形结构化正确率区分题干、公式、作答与图形，并保持空间对应。
B · 结构化与知识
数学 / 物理 Problem IR将对象、关系、约束与学生步骤转成可验证的中间表示。
学段知识与 KAS 检索难点② 定理与知识点 Grounding检索对应学段的定理、公式、知识点及适用条件。
C · Agent 推理与验证
解题 Agent基于结构化题目和检索知识规划候选解法。
图形 Agent解析几何、受力与运动关系。
符号 / 量纲工具用外部工具减少代数与计算幻觉。
验证与纠错 Agent难点③ 学科推理验证逐步检查定理条件、计算、约束与最终答案。
D · 诊断与教学
错因诊断高效定位孩子真正不懂的问题定位第一个认知断点，而不是笼统判错。
分层提示 + 正反馈难点④ 专注与互动策略动态选择追问、提示和正反馈，让学生保持参与。
板书 / 图上高亮 / 真人讲解同步白板、关键区域高亮、语音和讲解节奏。
L1 内容正确L2 当题理解L3 近迁移L4 延迟保持真正的教学效果，不是 AI 讲得多完整，而是学生之后需要更少帮助。
